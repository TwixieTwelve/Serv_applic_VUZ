# ARCHITECTURE — Электронная библиотека и каталог книг

## 1. Предметная область (ЛР №1)

Система «Электронная библиотека и каталог книг» автоматизирует основные процессы библиотеки: ведение
электронного каталога, учет физических экземпляров, регистрацию пользователей, выдачу и возврат книг,
бронирование экземпляров и учет штрафов за просрочку.

**Роли:** читатель (`reader`), библиотекарь (`librarian`).

## 2. Архитектура (ЛР №1)

Монолитная клиент-серверная архитектура (C4 Container):

- **Web Client** — пользовательский веб-интерфейс;
- **Backend Service** — REST API, бизнес-логика и обработка запросов;
- **PostgreSQL** — основная база данных;
- **Redis** — кэш часто запрашиваемых данных каталога.

## 3. Модель данных (ЛР №1)

Таблицы: `roles`, `users`, `authors`, `books`, `book_authors`, `book_copies`, `loans`, `reservations`, `fines`.

Связи: roles 1:N users; books 1:N book_copies; books N:M authors (через book_authors);
users 1:N loans; book_copies 1:N loans; users 1:N reservations; book_copies 1:N reservations;
users 1:N fines; loans 1:N fines.

## 4. REST API Specs (ЛР №2)

- Базовый адрес: `http://localhost:8080/api/v1`
- Формат: JSON (`application/json`), поля в snake_case
- Аутентификация: JWT, заголовок `Authorization: Bearer <token>`
- Единый формат ошибок: `ErrorResponse { code, message, timestamp, details }`
- Полная спецификация: [`openapi.yaml`](./openapi.yaml)

### Коды ошибок

| Код | Когда возвращается |
|-----|--------------------|
| 400 Bad Request | Невалидные входные данные (формат email, пустое название, неверный год) |
| 401 Unauthorized | Нет токена / токен истек / неверный логин или пароль |
| 403 Forbidden | Недостаточно прав (читатель пытается выполнить действие библиотекаря, отменить чужую бронь) |
| 404 Not Found | Ресурс с указанным id не найден |
| 409 Conflict | Экземпляр уже забронирован или выдан; дубликат ISBN, email или инвентарного номера; книга уже возвращена |
| 500 Internal Server Error | Необработанная ошибка сервера |
